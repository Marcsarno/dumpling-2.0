# Store kit — September 20, 2026

Created for the three reference-led store upgrades in the isolated Editor project.

- `bao-squishy-display.glb`: simplified from this project's original `../squishies/bao-squishy.glb`; 45,392 to 5,887 triangles. Original collectible colors, facial components and accessory identities are reused in Editor materials/entities.
- `bamboo-steamer-shelf-display.glb`: simplified from the project's original `../squishies/bamboo-steamer-shelf.glb`; 17,768 to 3,020 triangles. Original reward/reveal models remain unchanged.
- `arched-display-shelf.glb` and `store-kit.blend`: new project-authored, beveled double-sided shelf with rounded endcaps. No downloaded geometry.
- `sign-*.glb`: project-authored sign geometry and flowers; lettering generated using locally installed Windows Comic Sans Bold, exported as geometry. No font file is distributed. `sign-smiles` is available in the kit but not placed in the final stores.
- Other furniture, plants, carts, doors, windows and trees reuse the existing Kenney CC0 models. Their source links and license files remain in `../environment/kenney/sources.json` and the individual pack directories.
- Tables, checkout counters, bins, rugs, gift boxes and charm stands are native Editor primitives, generated by shared helper functions in `scripts/plan-store-upgrade.mjs`.

No new external asset purchase or download was used. Original project asset provenance is documented in `../squishies/SOURCES.md`.

Rebuild geometry with Blender 5.2 in background mode using `scripts/build-store-kit.py` and `scripts/build-store-signs.py`, from the isolated repository root. The sign script expects the Windows font path recorded in its source.

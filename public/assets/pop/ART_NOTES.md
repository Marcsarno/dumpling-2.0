# Squishy Pop art

Regular pieces: four new reference-led atlases covering 26 collectible IDs. The user explicitly clarified that existing in-game squishies are unfinished placeholders and must not be used. Art layout and ID mappings live in `src/ui/PopArt.ts`. The runtime crops each atlas cell into a cached 192px canvas; no per-frame image decoding.

# School reference assets

The two supplied concept images guide composition and colors; they are not included as in-game textures.

- Furniture and books: Kenney Furniture Kit, CC0: https://kenney.nl/assets/furniture-kit . Existing source models and license retained in ../environment/kenney/furniture.
- Food and drink cartons: Kenney Food Kit, CC0: https://kenney.nl/assets/food-kit . Source package retained in the local artifacts/food-kit/source folder. Geometry/palette reused at small serving sizes.
- Classmates and lunch attendant: Kenney Mini Characters, CC0: https://kenney.nl/assets/mini-characters . Existing rigged models and seated/idle poses retained in ../characters/classmates.
- The rest of the room geometry, school tables/chairs, backpacks, serving counter, windows, plants, signs, globe and rugs are original project geometry generated by scripts/build-school-kit.py in Blender. Text is converted to geometry using the locally installed Comic Sans Bold; no font file is distributed.
- Small maple/stone/woven surface maps and local contact shading are generated by that script and embedded in the GLBs. No new large textures or shadow-casting lights.
- The squishy display uses existing original game collectibles. Models are never copied from the reference image.

classroom.glb and cafeteria.glb are static render assets; adjacent collision JSON files are generated from the same furniture placements. Runtime characters, offers, navigation and trading are separate.
